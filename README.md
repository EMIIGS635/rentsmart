# RentSmart - Sistema de Orcamento de Locacao

Trabalho da disciplina **Algorithmic Thinking & Introduction to Object-Oriented Programming**.

RA: **241981**

Aplicacao em Python que calcula orcamentos de locacao da imobiliaria R.M Imoveis,
aplicando automaticamente as regras comerciais de cada tipo de imovel e gerando
um arquivo CSV com a projecao dos 12 meses do contrato.

---

## Como executar

1. Tenha o **Python 3** instalado (versao 3.8 ou superior).
2. Baixe o arquivo `rentsmart.py`.
3. Abra o terminal (ou prompt de comando) na pasta do arquivo e execute:

```
python rentsmart.py
```

O programa faz as perguntas no terminal. Ao final, ele mostra o orcamento na tela
e gera o arquivo `projecao_12_meses.csv` na mesma pasta.
